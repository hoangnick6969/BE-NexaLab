- (direction) Parent session asked for the full Teacher AI feature set as BMAD specs; this folder is TAI-03 question duplicate and submission similarity.
- (decision) Both parts are deterministic local computation with no provider call, so no student data leaves the server and no provider gate applies.
- (decision) Part A extends TAI-01 VW-01/VW-02 corpus to all non-archived resources in the teacher's own classes plus released SHARED_LIBRARY lesson questions; never other teachers' private classes.
- (decision) Algorithm qdup@1 reuses TAI-01 normalize and character-trigram Jaccard >=0.85; exact = normalized-text sha256 equality.
- (decision) QuestionFingerprint table maintained in the same transaction as resource create, update-draft, publish, revise and archive, plus a backfill script; corpus over 10000 items checks exact only and returns CORPUS_TRUNCATED.
- (decision) Same-class EXACT keeps blocking unedited AI accept (TAI-01); cross-class or library EXACT on AI items is warning EXACT_DUPLICATE_ELSEWHERE; direct authoring and CSV import only warn, never block.
- (decision) Part B algorithm subsim@1: per prompt, normalize, word tokens, drop tokens covered by prompt-text shingles, formula tokens and teacher-declared common phrases; word 5-gram shingles; winnowing window 4; containment = shared/min fingerprints.
- (decision) Responses with <40 eligible tokens are skipped as SHORT_RESPONSE; a pair is reported when containment >=0.60 and >=8 shared fingerprints; HIGH >=0.80, ELEVATED 0.60-0.79.
- (decision) Pairs only between current submissions of different students in the same assignment and same prompt; never across assignments or classes.
- (decision) Similarity runs are synchronous, bounded to 200 submissions, keyed by inputDigest + algorithmVersion; same digest replays the existing run; results immutable; reviews append-only (DISMISSED|NOTED).
- (decision) Results are REVIEW_REQUIRED evidence only; never change score, grade, status or notify students; students, parents and outsider teachers have no access.
- (constraint) Part B depends on TAI2-T2 written submission model; Part A depends only on TAI-01 validation pipeline.
- (capability) CAP-1 teacher sees duplicate warnings across own classes and shared library when authoring, importing or reviewing AI drafts; success: exact and near fixtures flag, other teachers' content never appears.
- (capability) CAP-2 fingerprints stay consistent with resource lifecycle; success: create/revise/archive update fingerprints atomically and backfill reconciles counts.
- (capability) CAP-3 teacher runs similarity on a written assignment and sees ranked pairs with matched spans; success: boundary fixtures pass, exclusions hold, rerun replays.
- (capability) CAP-4 teacher records a review note or dismissal per pair; success: append-only, score and grade untouched, no student-visible effect.
- (assumption) Thresholds 0.85 trigram, containment 0.60/0.80, 40 tokens, 8 fingerprints, 5-gram, window 4 are starting values to be tuned on pilot data under a new algorithmVersion.
