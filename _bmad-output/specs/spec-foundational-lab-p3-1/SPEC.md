# P3.1 Circuit candidate blueprint

The canonical master, shared contract and P3.x phase plan are in ../spec-lab-pipeline/. This folder preserves the initial discovery and owns the first Circuit activity blueprint, not a competing platform roadmap. Define is complete for the private engineering Build slice; the Outcome, activity and model are not curriculum/science approved and no Lab is released by this status.

The first activity uses a generic low-voltage bulb and switch to let a learner predict and observe closed and open circuits. Activity assessment is separate from model observations; a valid open circuit is not automatically a failed learning activity. B22 is a source mapping candidate, not approved Outcome coverage, and virtual interaction does not attest physical wiring skill.

Keep the existing LED 2 V, current-limiting model proposal and its 14 cases as historical, unapproved extension material. Existing circuit@1.0.0 has LED but no bulb and its raw not_passed on open circuit is unsuitable as this activity's rubric. Build a separately versioned bulb model and preserve legacy behavior/history rather than renaming LED as bulb.

The 30-candidate discovery catalog remains in the master spec. Its ~20 shortlist is provisional and never blocks the first technical pilot. Foundational practice is open subject to authentication; Class Lab is a future class-private configuration of a reviewed release. Prototype content and unreviewed UI stay outside public learner flows; tested infrastructure may be reused and existing attempts/saved experiments retained.

Source inventory and platform Build may run in parallel. Named curriculum and distinct scientific/model reviewers must review the exact mapping, model and rubric before a reviewed pilot or production release is claimed. P3.5 requires a second-model compatibility fixture after a real persisted technical attempt, before two Lab implementation tracks.
