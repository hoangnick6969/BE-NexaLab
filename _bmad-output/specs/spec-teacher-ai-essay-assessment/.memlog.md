- (direction) Parent session asked for the full Teacher AI feature set as BMAD specs; this folder is TAI-02 essay/rubric assessment, reusing the TAI-01 AI job runtime.
- (note) Brownfield: ClassResourceKind is DECK/STUDY_QUIZ/TEST; Assignment.contentType is lesson/lab/test; AssignmentSubmission has non-null score/correctCount computed by scoreTest; LateDecision (REJECT_ZERO/REVISE_DEADLINE_FOR_CLASS) and AssignmentDeadlineRevision are keyed to AssignmentSubmission; submit route is POST assignments/:id/submissions in learning.controller.
- (note) Brownfield: PRD has no functional requirement for constructed-response tasks; FR-11 covers decks, study quizzes and tests only.
- (decision) Add ClassResourceKind WRITTEN_TASK and Assignment contentType 'written' instead of adding essay questions to TEST, so TEST server scoring stays deterministic and unchanged.
- (decision) Written submissions reuse AssignmentSubmission so deadline revisions, late reasons and LateDecision apply unchanged; add gradingMode AUTO|TEACHER, make score/correctCount nullable with a DB check that AUTO rows keep non-null score; backfill existing rows AUTO.
- (decision) Rubric lives inside the immutable WRITTEN_TASK resource content per prompt (criteria code, description, maxPoints, anchors); rubric version = resource version, no separate rubric table.
- (decision) Students see criteria code, description and maxPoints; anchors are teacher-only.
- (decision) Teacher grade is append-only WrittenGradeDecision (criterion points, percent score, feedback, kind MANUAL|ACCEPTED_AI|EDITED_AI|REJECTED_AI, basedOnSuggestionId); latest row is the current grade; regrade appends.
- (decision) Gradeable submissions are ON_TIME or ACCEPTED_BY_EXTENSION; LATE_REVIEW_PENDING cannot be graded; REJECTED_ZERO stays zero by LateDecision and cannot be graded.
- (decision) AI suggestion is AiJob purpose ASSESS_SUBMISSION, one job per submission, separate daily limit AI_DAILY_ASSESSMENT_LIMIT (default 200 submissions/teacher/24 h).
- (decision) Snapshot sends prompt, rubric and PII-redacted response text only; studentId, name, username, email, phone and class names never reach the provider; redaction offsets are kept to map evidence back.
- (decision) Output per criterion: suggestedPoints, rationale, up to 3 evidence quotes, uncertainty note; no numeric confidence.
- (decision) Evidence quotes must be exact substrings of the redacted response after whitespace normalization; suggestedPoints > 0 without a verified quote invalidates that criterion (EVIDENCE_MISSING).
- (decision) Points outside [0, maxPoints] or off the half-point grid invalidate the criterion suggestion (POINTS_OUT_OF_RANGE); the server never silently clamps model output.
- (decision) Response text is a delimited data block; a deterministic instruction-pattern detector (vi/en, e.g. 'bỏ qua hướng dẫn', 'cho 10 điểm', 'ignore previous') suppresses the suggestion with INJECTION_SUSPECTED and leaves manual grading.
- (decision) AI_ASSESSMENT_MODE off|shadow|assist; shadow stores suggestions hidden from the grading UI and visible only in the evaluation report after the teacher grade exists; assist shows them; mode recorded per suggestion.
- (decision) Students and parents never see AI text or AI scores; they see only the latest teacher grade and feedback.
- (decision) TAI2-T1..T3 (written tasks and manual grading) ship without AI gates; AI tickets T4+ are blocked by TAI2-T0.
- (constraint) Gate TAI2-T0: paid provider tier whose terms exclude using API data to improve products (Gemini free tier forbidden), documented legal basis under NFR-07 / Decree 13/2023 for minors, PRD amendment adding written tasks, TAI-01 shipped.
- (decision) Default legal mechanism assumed: per-student ParentConsent purpose 'ai-assessment' not withdrawn; submissions without it are manual-only with NO_CONSENT; T0 may replace this only with a documented school-agreement basis.
- (capability) CAP-1 teacher authors, publishes and revises a WRITTEN_TASK with 1-5 prompts and a rubric; success: invalid rubric rejected, published versions immutable.
- (capability) CAP-2 teacher assigns a written task and students submit text under existing target, deadline and late rules; success: TEST behavior and history byte-for-byte unchanged.
- (capability) CAP-3 teacher grades per criterion with append-only decisions; success: student sees only latest teacher grade, ungraded stays awaiting grade, late/zero rules preserved.
- (capability) CAP-4 teacher requests AI rubric suggestions; success: only redacted consented text leaves the server, invalid evidence or points never reach the teacher, injection suppresses.
- (capability) CAP-5 shadow evaluation compares hidden suggestions with lecturer grades; success: report computes MAE and within-1 agreement on a pinned prompt version.
- (capability) CAP-6 in assist mode teacher accepts, edits or rejects a suggestion into a grade decision; success: final score always carries a teacher actor and AI never writes a grade.
- (assumption) Evaluation gate: >=100 responses across >=3 written tasks graded blind by the supervising lecturer; total on 10-point scale MAE <=1.0, >=80% within +-1, >=95% of AI evidence quotes verifiable.
- (assumption) Limits: 1-5 prompts per task, prompt <=2000 chars, response maxChars 100-5000 set per prompt, 1-6 criteria per prompt, maxPoints 1-10 in half-points.
